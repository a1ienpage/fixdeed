# Fixdeed Competition Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a tested Fixdeed upgrade with a demonstrable paid workflow and an evidence-based 10-slide Zimran PDF.
**Architecture:** Extend the existing deterministic triage and browser-local store. Keep pure domain logic separate from React screens, then connect saved cases, quote comparison, calendar downloads and explicit demo entitlement.
**Tech Stack:** Existing Next.js 16.4.6, React 19, TypeScript, Zod, Vitest. No additional runtime packages.
**Spec:** docs/superpowers/specs/2026-11-15-finalist-design.md

## Global Constraints
- US B2C, ages 25–45, English UI, Money main track, browser only.
- Never gate safety or personal data export/deletion. No fabricated traction, payments, public URLs or professional validation.
- Plus is a clearly labeled demo entitlement at proposed $59/year or $7.99/month. No card entry or real billing.
- Preserve personal/demo isolation and backward compatibility. Personal notes and quotes remain browser-local.
- At most 10 total pitch slides. All business assumptions labeled, primary factual sources cited.

## Review Focus
- Negation must not suppress a separate active or uncertain hazard.
- Conversation must keep higher safety floors and advance from explicit supported answers.
- Old saved cases must retain original observations/result and not imply current safety after edits.
- Calendar files must have stable IDs, correct monthly recurrence, escaped user text and visible manual-import limits.
- Annual/monthly LTV assumptions and competitive prices must be internally consistent and labeled.
